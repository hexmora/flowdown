# Flowdown

Flowdown is an extensible, headless-capable, reactive, high-performance Markdown rendering library designed for LLM streaming scenarios.

It separates Markdown stream computation from framework rendering so applications can build custom renderers, preserve responsive updates, and keep UI work efficient while text is still arriving.

## Packages

- `@flowdown/core`: headless computation for streaming Markdown.
- `reactive`: headless reactive primitives for streaming state.
- `flowdown`: React rendering bindings built on top of core.
